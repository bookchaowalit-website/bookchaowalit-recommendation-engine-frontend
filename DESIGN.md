# Glyph / Rank — Design System

## Overview

Glyph / Rank is a phosphor signal lab for a transparent tag-overlap recommender. The interface behaves like a live character field: the visitor changes the input vector and reads the ranked records without mistaking the demo for a trained model.

## Colors

- Ink ground: #07110D.
- Ink soft: #0D1B14 and grid line: #193329.
- Phosphor green: #B6FF6A for active text and evidence.
- Dim phosphor: #6CAE4F for quiet metadata.
- Amber: #FFBD68 for state and measurement.

## Typography

- Georgia is the display voice: large, literary, slightly irregular.
- Geist Sans carries explanatory copy and record titles.
- Geist Mono is reserved for tags, scores, labels, and the local boundary.
- Display headings are tight and oversized; body copy stays in a readable 55ch measure.

## Layout

- A bordered signal frame holds masthead, thesis, input vector, ranking field, and footer.
- The first viewport proves the mechanism with the active vector readout.
- Input tags are a compact matrix; ranking rows are a measured field with position, trace, and density.
- Mobile collapses the ranking row into record copy over its density readout.

## Elevation & Depth

- Depth comes from the dark frame, faint phosphor field, and restrained soft shadow.
- Active rows use a low-opacity phosphor wash; no floating card stack is used.
- The ranking bars are evidence, not decoration.

## Shapes

- Square controls, hairline borders, and clipped grid marks create a terminal instrument grammar.
- No rounded cards, gradients, or decorative icons.
- The green field is broken only by amber state marks.

## Components

- Masthead: product name, local status, and no-model boundary.
- Input tag: binary mark, tag name, ON/OFF state, and pressed behavior.
- Ranking row: rank, record title, tag trace, density bar, and score.
- Readout: compact active-vector count that connects the control to the result.

## Do's and Don'ts

- Do make the score legible and keep the local-only boundary visible.
- Do use mono for measurement and sans/serif for meaning.
- Don't imply personalization, ML quality, or a remote catalog.
- Don't add dashboard-style KPI cards or generic neon decoration.
